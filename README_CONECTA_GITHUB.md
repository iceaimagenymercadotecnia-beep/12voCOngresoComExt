# CONECTA I+D+i | ICEA

## Publicación en GitHub Pages
Sube **el contenido de esta carpeta** a la raíz del repositorio (no la carpeta contenedora). Activa Settings > Pages > Deploy from a branch > main / (root). La página principal es `index.html`.

## Contenido
- `index.html`: portada general CONECTA I+D+i con cuatro eventos.
- `congreso-icea.html`: página previa del 12.º Congreso ICEA.
- `comercio-exterior.html`, `administracion.html`, `foro-turismo.html`: espacios informativos en preparación.
- `investigacion.html`: módulo de investigación en preparación.
- `registro-demo.html` y `prototipo-directora.html`: demostraciones sin almacenamiento real.
- `portal.html` y `assets/`: prototipo técnico heredado, aún no apto para registro público.
- `supabase/`: archivos técnicos; NO ejecutar scripts SQL sin revisión, migraciones y pruebas.

## Importante
Este ZIP NO habilita autenticación, registro real, cobros, dictámenes ni emisión de constancias. Para lanzar inscripciones se requiere configurar Supabase, permisos por evento, pruebas de seguridad y pruebas de extremo a extremo. Los logotipos y fotografías definitivos deben validarse con Imagen Institucional.
